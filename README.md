Data Analytics Internship – Task 17 (Monthly Sales Trend)

This repository contains my submission for Task 17 of the Data Analytics Internship.

Dataset - Retail Sales Dataset

Objective - The objective was to summarize sales by month and visualize the monthly sales trend using Excel.

Tools Used
1. Microsoft Excel
2. Retail Sales Dataset
3. GitHub

Analysis Performed
1. Used the Retail Sales Dataset containing transaction dates and sales amounts
2. Grouped sales by month using Excel formulas
3. Calculated monthly sales using SUMIFS
4. Kept the months in chronological order
5. Created a line chart to visualize the monthly sales trend

Final Results
1. Monthly sales were calculated for the dataset
2. January to December were arranged in chronological order
3. A line chart was created to show the monthly sales trend
4. The chart helps identify changes in sales across different months

Files
1. Task 17.xlsx - Excel workbook containing Raw Data and Monthly Sales Trend
2. README.md - Summary of the monthly sales trend analysis

Conclusion - The Retail Sales Dataset was successfully analyzed using Excel to calculate monthly sales and visualize the sales trend using a line chart.
